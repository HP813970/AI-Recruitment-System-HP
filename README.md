## Explainable Recruitment Assistant

**README Prose Word Count:** 436

### Project Status

This project is an Explainable Recruitment Assistant which a prototype designed to improve transparency and human oversight in AI-assisted recruitment

Implemented features:
- Candidate review dashboard
- Candidate ranking interface
- Recommendation explanation views
- Feature importance explanations
- Confidence score explanations
- Candidate comparison explanations
- Human review stage
- Feedback and recovery functionality

Simulated features:
- AI recommendation and evaluation engine
- Recommendation confidence calculations

Planned features:
- Bias auditing tools
- Adaptive learning from manager feedback
- Real candidate database integration
- Personalised explanation preferences

---

### Technology Stack

- HTML: used for the page structure and content
- CSSL: used to design and style pages
- JavaScript: contains the interaction logic and simulated AI evaluation behaviour

### Running the project locally

Requirements: Visual Studio Code and Python 3 must be installed to run the project

1. Download the project by going to Code -> Local -> Download Zip
2. Extract the folder and then open it in Visual Studio Code
3. Open a new terminal
4. Run:

```bash
py -m http.server 8000
```

5. Open the URL specified in a web browser:

```text
http://localhost:8000
```

#### Stopping the system

Press:

```text
Ctrl + C
```

in the terminal

### Development Record

#### Initial Concept

The original concept was focused more on displaying candidate rankings and recommendation scores rather than going into and creating detailed explanations

#### Major Development Change

Based on the A1 report, I shifted the development focus from recommendation accuracy to instead recommendation explainability and transparency

#### Features Added

- Visible evaluation criteria
- Feature importance explanations
- Confidence score explanations
- Candidate comparison explanations
- Human review functionality
- Feedback and recovery mechanisms

#### Reason for the Change

The reason behind this change is due to the A1 report findings which showed that hiring managers often struggle to understand how AI recruitment systems create recommendations and this led to prioritising transparency, explainability and human oversight over recruitment automation and applicant management functionality
when building the system
